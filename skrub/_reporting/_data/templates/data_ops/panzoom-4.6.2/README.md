`panzoom.min.js` is the UMD build of [`@panzoom/panzoom`](https://github.com/timmywil/panzoom)
(v4.6.2), used to pan and zoom the graph in the DataOps report
(`skb.full_report()`), without requiring a network connection.

Downloaded from https://cdn.jsdelivr.net/npm/@panzoom/panzoom@4.6.2/dist/panzoom.min.js
(sha256 `3ce354ef7b493efb62a4d4acaaf86fa2d6027eb629857a4e144041de1a112c1e`).
