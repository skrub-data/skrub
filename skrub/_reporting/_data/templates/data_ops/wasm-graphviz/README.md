This directory contains the files needed to draw the DataOps graph in the
browser when Graphviz is not installed on the machine (see `GraphDrawing` in
`skrub/_data_ops/_inspection.py`), without requiring a network connection when
displaying a `.skb.report()`.

The drawing is done by [`@hpcc-js/wasm-graphviz`](https://www.npmjs.com/package/@hpcc-js/wasm-graphviz)
(v1.29.2), a WebAssembly build of [Graphviz](https://graphviz.org/). It is
distributed under the Apache License 2.0 (see `LICENSE` in this directory) and
embeds Graphviz, which is distributed under the Eclipse Public License
(https://graphviz.org/license/).

- `graphviz.js`: the library, generated by `make_classic_script.py`. Do not
  edit it manually. It is written in a `<script>` element in the report's
  `index.html` and in the page created by `GraphDrawing.open()` (it is read in
  `_get_jinja_env`, and not loaded as a template because it contains sequences
  that jinja would interpret). The package is an ES module (the WebAssembly
  binary is embedded in the JavaScript file), but browsers do not allow loading
  local ES modules from `file://` pages, where reports are opened. So the script
  downloads the package from
  https://cdn.jsdelivr.net/npm/@hpcc-js/wasm-graphviz@1.29.2/dist/index.js,
  checks its hash, and turns it into a classic script: the final `export`
  statement is replaced by an assignment to `window.skrubGraphviz` and the code
  is wrapped in a function so it does not define global variables.
- `make_classic_script.py`: run it with `python make_classic_script.py` to
  regenerate `graphviz.js`.

DataOps displayed in notebooks (`render_dot_fragment.html`) load the same
version of the original package from the CDN instead, because the library is too
large to include in every cell output.

To update the library: change `VERSION` and `SHA256` in `make_classic_script.py`
(and `LICENSE` if it changed), run the script, and update the CDN URL in
`render_dot_fragment.html`. `test_vendored_graphviz_library` (in
`skrub/_data_ops/tests/test_inspection.py`) checks that the version in the header
of `graphviz.js` matches the one in `render_dot_fragment.html`.
